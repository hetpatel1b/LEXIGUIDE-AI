# Feature: Document Upload

## Purpose
Manages document ingestion, client-side format/size validation, and upload status management.
- Handles PDF, DOCX, and TXT files within the 25MB constraint.
- Manages drag-and-drop dropzone, upload progress states, and error handling.
- Interfaces with server-side document processing in Phase 2.

## Target Phase
Phase 1C (Upload UI Shell) & Phase 2 (Real Document Ingestion Pipeline).
