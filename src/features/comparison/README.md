# Feature: Document Comparison

## Purpose
Provides side-by-side comparison across contract iterations or conflicting drafts:
- Dual document mapping (Document A vs Document B)
- Clause-by-clause difference highlights (added, removed, modified)
- Conflict and inconsistency detection
- Evidence citation linkage

## Target Phase
Phase 1E (Comparison UI Shell) & Phase 5 (Comparison & Inconsistency Engine).
