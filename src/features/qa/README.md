# Feature: Grounded Q&A (Ask Your Document)

## Purpose
Enables users to ask specific questions about analyzed documents with strict legal grounding:
- Natural language query interface
- Direct quotation and page/section citation
- Factual confidence scoring
- Follow-up query recommendations

## Target Phase
Phase 1D (Q&A UI Shell) & Phase 4 (Evidence Retrieval & Nemotron Q&A Engine).
